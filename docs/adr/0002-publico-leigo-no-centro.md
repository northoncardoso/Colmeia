# ADR 0002: público leigo no centro do produto

**Status:** aceito
**Data:** 2026-11-27

## Contexto

Redes científicas existentes, como o ResearchGate, tratam o pesquisador como único usuário relevante. Redes sociais genéricas distribuem conteúdo sem compromisso com fonte. O projeto nasce para levar ciência a quem não tem a informação.

## Decisão

O leitor que não é pesquisador é o usuário principal. Toda decisão de produto é avaliada primeiro por esse critério. O pesquisador é usuário essencial, mas a experiência dele é meio para o leigo entender, não fim.

## Consequências

* A home precisa explicar o produto em uma frase, sem jargão.
* O Mel é obrigatório, não opcional.
* Métrica norte é leitor leigo recorrente, não número de pesquisadores cadastrados.
* A linguagem da interface evita termos como DOI, preprint e revisão por pares sem explicação.
* A verificação de pesquisador existe para dar confiança, não para criar elite.

## Alternativas descartadas

* Começar como rede só de pesquisadores e abrir para o público depois: risco de nascer com cultura errada.
* Copiar o ResearchGate com camada de tradução: o leigo continuaria sendo visitante, não cidadão.
